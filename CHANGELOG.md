# Changelog

## 0.1.3 — first public release candidate

- Rebuilt using a strict allowlist of previously reviewed source files.
- Added six owner-approved benchmark measurements, two newly sanitized charts, and a limited benchmark methodology.
- Clarified that power is combined, stage-mean GPU power; independent per-GPU instantaneous data is not available in this release.
- No proprietary project code, host-specific GPU clock controller, personal media, private logs or private payment details included.
- Viewer remains read-only; request governor remains experimental.
